# Ahrefs Changelog: Running List of New Features

This is the Ahrefs changelog, a simple list of all our newest features for you to browse.

If you prefer video, head to our [product updates channel](https://www.youtube.com/@ahrefsupdates/videos) instead 😉

### The pace we ship at

Stats from September 2025 to April 2026:

![](https://ahrefs.com/blog/wp-content/uploads/2024/06/ahrefs-stats.jpg)

-

**22 May**: Brand Radar reports now provide AI visibility insights across across all platforms at once, rather than having to check specific platforms (though this is still an option). By default, reports will show combined data across prompt-based platforms, including new indexes we have for AI Overviews and Google’s AI Mode.

**22 May**: We’ve released new indexes for AI Overviews and AI Mode in Brand Radar. These indexes are focused on long-form style queries, rather than including short terms from our Keywords Explorer database. The previous AIO and AI Mode indexes are still available to select, but only the old AIO index will continue to update.

**21 May**: Lite, Standard, Advanced and Enterprise v2 customers can now add up to 20 competitors (vs 10 previously) to their projects, while Enterprise v3 can add up to 100. These limits are supported in the Dashboard as well as Site Explorer, Rank Tracker, and Competitive Analysis tools. Please note that Content Gap and Link intersect functionality is capped at 20 competitors.

**21 May**: In the GSC Insights tool there’s now an option to see and export aggregated metrics across all keywords and pages. This applies to comparison history charts in the *Keywords*, *Keyword lists* and *Pages* reports.

**15 May**: We’ve added two additions to the Site Audit tool to help you understand and fix issues the tool highlights. A *Fix with Agent A* button sends current issues to Agent A to investigate (which also has the ability to implement changes based on your connectors). *Copy for AI* in the API button provides all the meta info you need, ready to paste as markdown for your AI assistant of choice.

**15 May**: Two new additions have been made to the Ahrefs API, specifically relating to Brand Radar. Firstly, you can now filter by tags across all Brand Radar endpoints (AI responses, cited pages, etc.). Also, when creating a custom report, you can now provide brand entities (with brand variations and domains). View the [Brand Radar API docs](https://docs.ahrefs.com/en/api/reference/brand-radar) to learn more.

**15 May**: You can now search across the entirety of ahrefs.com (main site, blog, and help center) from a single search box, powered by Yep. Click the search icon in the header, or use either **/** or **CMD/Ctrl+K** shortcuts for it to appear.

**14 May**: We’ve added a small but useful feature to the Content gap keyword table: The ability to *Select all* keywords at once, not just what’s in the current view.

**13 May**: The *Competitors* chart in Site Explorer has new functionality: If the target site is associated with an Ahrefs project, the resulting competitors are now pulled from its settings. Previous Overview-specific competitors are available in the “custom” tab.

**13 May**: The *AI Citations* widget in Site Explorer now shows Grok data. It’s included in a new secondary table which allows for showing AI visibility across more platforms.

**13 May**: The GSC Insights tool now supports viewing aggregated metrics for custom keyword lists, allowing you to check the performance of each independently.

**13 May**: Social Media Manager tool users can now view and reply to comments on their social media posts. The new *Comments Inbox* feature shows comments from LinkedIn, X, Facebook, Instagram, and Threads, and also offers marking as open/closed, filtering, and a threaded conversation view.

**12 May**: We’ve improved the navigation of our Local SEO product to match the rest of the Ahrefs dashboard interface. This change also adds a Business filter which persists across tabs.

**12 May**: We’ve added two new columns to the *Yours* tab of cited pages in Brand Radar: **Bot visits** and **AI traffic**. These cross-reference data from our Bot Analytics and Web Analytics products and provide insights into how many bot and human visits each page receives.

**11 May**: We’ve begun rolling out updates to our crawler scheduling system. This should continue to help ensure Ahrefs crawls more valuable pages that marketers care about, and fewer spam and low-value pages.**8 May**: Review management is now possible thanks to a big update to our Local SEO product. Users can now see reviews and ratings for Google businesses across all locations, in a single dashboard. You can also reply inline, or in batches, if you would like to respond to feedback.

**4 May**: We’ve added the “Top organic pages” widget set to Report Builder. You can filter the top pages by Traffic, Winners, Losers, New and Lost variants.

**1 May**: Agent B, our AI chat assistant available across Ahrefs tools, has launched in beta. Agent B can see the page you’re on and summarize insights, explain metrics, help with competitor comparisons, and even help perform actions on your behalf. To access Agent B, simply click on the standard question mark (?) in the bottom right corner of the Ahrefs interface.

**30 Apr**: There’s a new metric for the *Keywords* report in GSC Insights: The average position of the highest-ranking URL. This can be useful to monitor when you have multiple URLs ranking for the same term, such as a branded query.

**28 Apr**: We’ve massively increased API limits for Lite, Standard and Advanced plans. In this AI era, we’re opening up more data to power your marketing. Changes depend on your account level, but as an example, Standard plans now get 2.67x more credits and up to 10x more rows per request.

**24 Apr**: Grok responses are now available to monitor in Brand Radar for both Ahrefs prompts and custom prompts. It’s available in the All indexes add-on or available as a separate subscription. Note that a separate subscription is *not* required to track Grok responses for custom queries.**23 Apr**: After recently adding portfolio support to GSC Insights reports, we’ve now updated the corresponding view in Dashboard → Portfolios. This provides an overview into the performance of multiple portfolios from a single page.

**23 Apr**: You can now export charts from the *Organic keywords* and *Organic positions* charts in Site Explorer. Previously, you could only export the history of organic keywords and positions which had a location filter.

**22 Apr**: Our GSC Insights tool now has a new *Keyword* filter. Match single or multiple rules by *Phrase match* and *Partial match*. You can enter multiple values at once, separated by commas.

**22 Apr**: The *Keywords* report in our GSC Insights tool has two new filters: **Word count**, and **Rank tracker status**. The latter lets you quickly see performance of terms you do or don’t track in Ahrefs’ Rank Tracker tool.

**22 Apr**: The Social Media Manager Overview page has received a major redesign. Now, instead of only seeing follower counts, you get a full snapshot of your social media channels and performance. This includes quick stats, upcoming posts, top posts by views, and follower counts for connected channels.

**21 Apr**: The Cited pages report in Brand Radar now shows the average position a page was cited. The table also gets three new columns: *Found in*, *Cited in*, and *Avg. position*. It’s now much easier to see when pages are found but not cited, across results.

**21 Apr**: The prompt details panel for AI responses in Brand Radar has received a design upgrade. You can now clearly see both cited pages, and URLs found but not cited.

**21 Apr**: A new *Site structure* report has been added to both Web Analytics and Bot Analytics. Similar to reports in Site Explorer and GSC insights, it shows website paths in a tree-like format. This helps you see which website sections account for the most website traffic, and which bots (such as AI bots) are focused on.

**18 Apr**: We’ve added interactive widgets to the Ahrefs MCP. Claude and ChatGPT now render scorecards, time-series charts, and table reports in chat responses. Each widget also links to the corresponding Ahrefs report for further analysis.

**18 Apr**: Brand Radar API endpoints now support brand name variations and websites, matching the standard Ahrefs UI. To handle these more complex inputs, we created POST versions of our existing GET endpoints. You can learn more about the changes on our official [developer documentation](https://docs.ahrefs.com/api/reference/brand-radar/post-ai-responses).

**18 Apr**: The Ahrefs MCP is now available in the official ChatGPT apps directory. While our MCP worked with ChatGPT previously, it required a manual set-up process, which is no longer required. Now it’s easier to use Ahrefs data to power your marketing projects.

**7 Apr**: We’ve added three usability improvements to Ahrefs’ Social Media Manager. A new date range filter supports presets or custom dates, including forward-looking ranges for scheduled posts. You can search post captions for specific keywords, and also sort published posts by metrics like *comments* and *likes*.

**6 Apr**: Keywords Explorer now shows historical search volume trendlines for multiple keywords, or a saved keyword list. The chart features the combined search volume of all terms, and how that has changed over time.
