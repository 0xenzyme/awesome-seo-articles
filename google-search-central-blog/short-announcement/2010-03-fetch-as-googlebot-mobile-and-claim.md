# Fetch as Googlebot Mobile and Claim your Sidewiki comment - added to Webmaster Tools Labs!

Last October, we launched
[Webmaster Tools Labs](/search/blog/2009/10/fetch-as-googlebot-and-malware-details)
and it has been a huge success. Malware Details have helped thousands of users identify pages on
their site that may be infected with malicious code, and Fetch as Googlebot has given users more
insight into our crawler.

Today, we're happy to announce two additional Labs features:

- Fetch as Googlebot-Mobile
- Create your Sidewiki page owner entry

## Fetch as Gooblebot Mobile (developed by Ryoichi Imaizumi)

After we launched Fetch as Googlebot, many users with mobile-specific sites asked if we could
provide the ability to fetch their pages as Googlebot-Mobile. We thought it was a great idea, and
added it as an option to our Fetch as Googlebot feature. We have two mobile options: cHTML
(primarily used for Japanese sites), and XHTML/WML.

![The Fetch as Googlebot Mobile feature in Webmaster Tools labs](/static/search/blog/images/import/5858312f251839e90fe0136431d8f5c9.png)

## Create your Sidewiki page owner entry (developed by Derek Prothro)

[Sidewiki](https://www.google.com/sidewiki)
allows users to contribute helpful information to any webpage using a sidebar in Google Toolbar
or a
[Chrome extension](https://chrome.google.com/extensions/detail/fldmleagmkblgoeodhdlhdejhhngdihi).
Webmasters can create a special entry, called a
[page owner entry](https://www.google.com/support/toolbar/bin/answer.py?answer=157270),
that appears above all entries written by users.

![An example Sidewiki](/static/search/blog/images/import/a12df0f8c4a10e89737c399aa459718f.jpg)

After Sidewiki launched webmasters kept asking, "How can I put a Sidewiki page owner entry on all
pages of my site quickly?" With the feature that we're introducing today, you can now create these
page owner entries directly within Webmaster Tools for any site you own.

![The Sidewiki page owner feature in Webmaster Tools labs](/static/search/blog/images/import/3ad3239f9eaa07a285431bad156797a7.png)

We're really happy about these new features, and hope you enjoy them as much as we do. Let us know
[what you think](https://support.google.com/webmasters/community/label?lid=462896acb3879639)!
