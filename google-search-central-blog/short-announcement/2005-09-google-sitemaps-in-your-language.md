# Google Sitemaps in your language

We've just made our Sitemaps user interface and documentation available in ten additional
languages. We have also set up Google Groups for each one. The languages available are:

- [Brazilian Portuguese](/search/docs/crawling-indexing/sitemaps/overview?hl=pt-br)
- [Dutch](/search/docs/crawling-indexing/sitemaps/overview?hl=nl)
- [French](/search/docs/crawling-indexing/sitemaps/overview?hl=fr)
- [German](/search/docs/crawling-indexing/sitemaps/overview?hl=de)
- [Italian](/search/docs/crawling-indexing/sitemaps/overview?hl=it)
- [Korean](/search/docs/crawling-indexing/sitemaps/overview?hl=ko)
- [Russian](/search/docs/crawling-indexing/sitemaps/overview?hl=ru)
- [Simplified Chinese](/search/docs/crawling-indexing/sitemaps/overview?hl=zh-cn)
- [Spanish](/search/docs/crawling-indexing/sitemaps/overview?hl=es-419)
- [Traditional Chinese](/search/docs/crawling-indexing/sitemaps/overview?hl=zh-tw)
- [UK English](/search/docs/crawling-indexing/sitemaps/overview?hl=en)
- [US English](/search/docs/crawling-indexing/sitemaps/overview?hl=en)

If you already use Google in one of these languages, you should see the change automatically.
Otherwise, you can click the Preferences link from the
[Google home page](https://www.google.com/) and choose one of
these languages from the interface list.

As always, you can submit a Sitemap for sites with content in any language.
