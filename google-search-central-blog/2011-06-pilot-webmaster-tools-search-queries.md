# Pilot Webmaster Tools' Search Queries data in Google Analytics

Webmasters have long been asking for better integration between
[Google Webmaster Tools](https://www.google.com/webmastertools) and
[Google Analytics](https://www.google.com/analytics/).
Today we're happy to announce a limited pilot for
[Search Engine Optimization reports](https://www.google.com/support/analyticshelp/bin/topic.py?topic=1308589)
in Google Analytics, based on
[Search Queries](https://www.google.com/support/webmasters/bin/answer.py?answer=35252)
data from Webmaster Tools.

In addition to including Search Queries data found in Webmaster Tools, these Search Engine
Optimization reports also take advantage of Google Analytics' advanced filtering and visualization
capabilities for deeper data analysis. For example, you can filter for queries that had more than
100 clicks and see a chart for how much each of those queries contributed to your overall clicks
from top queries.

![The Search Engine Optimization report in Google Analytics](/static/search/blog/images/archived_1_viz.png)

To enable these Search Engine Optimization reports, you should
[sign up for the pilot](https://docs.google.com/forms/d/1kdLPoGw5T4Z9QxWbsyHBI5jsvLxHsSoP7R-asBVVKUU/closedform#gid=0) and you must be
both a Webmaster Tools verified site owner and a Google Analytics administrator. Each additional
user who would like to view them also needs to individually
[sign up](https://docs.google.com/forms/d/1kdLPoGw5T4Z9QxWbsyHBI5jsvLxHsSoP7R-asBVVKUU/closedform#gid=0) for the pilot.
