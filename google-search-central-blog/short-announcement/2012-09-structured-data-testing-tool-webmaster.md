# Structured Data Testing Tool

Today we're excited to share the launch of a shiny new version of the rich snippet testing tool,
now called the
[structured data testing tool](https://www.google.com/webmasters/tools/richsnippets).
The major improvements are:

- We've improved how we display rich snippets in the testing tool to better match how they appear
  in search results.
- The brand new visual design makes it clearer what structured data we can extract from the page,
  and how that may be shown in our search results.
- The tool is now available in languages other than English to help webmasters from around the
  world build structured-data-enabled websites.

Here's what it looks like:

![View of the new Structured data testing tool](/static/search/blog/images/import/4ce0dc87604f8de113f0ef2a91171359.png)

The new structured data testing tool works with all supported rich snippets and
[authorship](https://plus.google.com/authorship)
markup, including
[applications](/search/docs/appearance/structured-data/software-app),
[products](/search/docs/appearance/structured-data/product),
[recipes](/search/docs/appearance/structured-data/recipe),
[reviews](/search/docs/appearance/structured-data/review-snippet), and others.

[Try it](https://www.google.com/webmasters/tools/richsnippets)
yourself and, as always, if you have any questions or feedback, please tell us in the
[Webmaster Help Forum](https://support.google.com/webmasters/community).
