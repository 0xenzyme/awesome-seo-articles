# More language support

We've added support for four more languages and a Sitemaps Google Group for each one:

- [Danish](https://groups.google.com/group/google-sitemaps-da)
- [Finnish](https://groups.google.com/group/google-sitemaps-fi)
- [Norwegian](https://groups.google.com/group/google-sitemaps-no)
- [Swedish](https://groups.google.com/group/google-sitemaps-sv)

As with the other languages we support, if you already use Google in one of these languages, you
should see the user interface and documentation automatically. Otherwise, you can click the
Preferences link from the
[Google home page](https://www.google.com/) and choose the
language from the interface list.
