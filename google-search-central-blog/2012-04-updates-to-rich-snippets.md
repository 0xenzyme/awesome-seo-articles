# Updates to rich snippets

Today we're announcing two updates to
[rich snippets](/search/docs/appearance/structured-data/search-gallery).
First, we're happy to announce that
[product rich snippets](/search/docs/appearance/structured-data/product),
which previously were only available in a limited set of locales, are supported globally.
Users viewing your site's results in Google search can now preview information about products
available on your website, regardless of where they're searching from. Here's an example of a
product rich snippet:

![A product rich snippet from www.google.fr](/static/search/blog/images/import/2b683976bb2c8ab06625b38d84096931.png "A product rich snippet from www.google.fr")

Second, we've updated the [rich snippets testing tool](https://www.google.com/webmasters/tools/richsnippets)
to support HTML input. We heard from many users that they wanted to be able to test their HTML
source without having to publish it to a web page. This is now supported by the tool, as shown
below.

![Preview rich snippets from HTML source](/static/search/blog/images/import/77f99bda5d6710d66999341daa055937.png "Preview rich snippets from HTML source")

If you have any questions or feedback about these changes, please let us know in our
[Help Forum](https://groups.google.com/a/googleproductforums.com/forum/#!forum/webmasters).
You can find more information about rich snippets in our
[Help Center](https://support.google.com/webmasters) and
[Webmaster Education](/search/docs/appearance/structured-data/search-gallery) site.
