# Links, Mobile Usability, and site management in the new Search Console

More features are coming to the
[new Search Console](/search/blog/2018/01/introducing-new-search-console). This time
we've focused on importing existing popular features from the old Search Console to the new
product.

## Links Report

Search Console users value the ability to see links to and within their site, as Google Search
sees them. Today, we are rolling out the new
[Links](https://support.google.com/webmasters/answer/9049606) report,
which combines the functionality of the "Links to your site" and "Internal Links" reports on the
old Search Console. We hope you find this useful!

![the Links report in Search Console](/static/search/blog/images/import/ac6b79c178bdf8a2bedbc10629cedf1a.png)

## Mobile Usability report

[Mobile Usability](/search/mobile-sites) is an important priority for all site owners.
In order to help site owners with fixing mobile usability issues, we launched the Mobile Usability
report on the new Search Console. Issue names are the same as in the old report but we now allow
users to submit a validation and reindexing request when an issue is fixed, similar to other
reports in the new Search Console.

![view of the Mobile Usability report in Search Console](/static/search/blog/images/import/2e55faa7782e73f90d0ee0e3e0ac2110.png)

## Site and user management

To make the new Search Console feel more like home, we've added the ability to add and verify new
sites, and manage your property's users and permissions, directly in new Search Console using our
newly added
[settings](https://support.google.com/webmasters/answer/7687465) page.

![view of the user management dashboard in Search Console](/static/search/blog/images/import/8cb592da7767a803fad08d499912d3f9.png)

## Keep sending feedback

As always, we would love to get your feedback through the tools directly and our
[help forums](https://support.google.com/webmasters/go/community)
so please share and let us know how we're doing.
