# Sitemaps in Japanese

Last week, we added support for Japanese. As with the
[other languages we support](/search/blog/2005/09/google-sitemaps-in-your-language),
if you already use Google in Japanese, you should see the user interface and documentation in
Japanese automatically. Otherwise, you can click the Preferences link from the
[Google home page](https://www.google.co.jp/) and choose Japanese
from the interface list.

We have also added a
[Japanese Sitemaps Google Group](https://support.google.com/webmasters/community?hl=ja).
