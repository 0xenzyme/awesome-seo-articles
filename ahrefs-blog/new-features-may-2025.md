# Global keyword metrics, unveiling anonymous queries, and more (May 2025)

This month’s highlights include outbound link clicks in Web Analytics, global keyword metrics in Organic keywords report, and more.

Let’s get right into it.

## Report Builder

**GSC performance charts**

You can now add GSC performance charts directly to Report Builder for:

- Total clicks
- Total impressions
- Average CTR
- Average position

It’s a faster, clearer way to monitor search performance without jumping between tools. More GSC widgets are already in the works.

![](https://ahrefs.com/blog/wp-content/uploads/2025/05/image9.png)

## Web Analytics

**Outbound link clicks**

Web Analytics now tracks outbound link clicks – so you can see which external links are catching your visitors’ attention.

Click in to see the specific links that were clicked, then click again on any link to reveal its referring page in the Top pages widget.

From there, it’s easy to spot which content is sending traffic offsite – and why.

## Site Explorer

**Paid keywords 3.0**

We’ve made a big upgrade to how the new Paid keywords report works behind the scenes.

Before, we only showed data from the latest SERP. The problem: ads change all the time,  so a ton of paid keywords were getting missed. Now, if we don’t spot your target in the latest SERP, we automatically check older ones – up to 30 days back. That way, we catch more ad placements and surface way more data.

Here’s a real example: for monday.com in the US, the old report found around **9.9k** paid keywords.

With the new data logic in Paid keywords 3.0, we’re seeing nearly **20k**. That’s almost 2× more coverage.

We’re rolling this improved logic out across all paid reports next, so expect a big jump in keyword visibility.

**Global keywords metrics in Organic keywords**

Here’s something we know a lot of you have asked for: we’ve added global keyword metrics in the Organic keywords report.

Toggle Global on to see global search volumes and traffic for every keyword, along with a list of all countries where your site ranks. It’s an easy way to get the full picture of your brand’s search demand worldwide – without having to jump between multiple location reports.

## AI Content Helper

**Editable topics**

Topics just got a lot more flexible. You can now edit topic cards however you like – add new ones, tweak what’s there, or remove anything that doesn’t fit.

Need inspiration? Just click “Ask AI” to generate instant, on-topic suggestions that help expand your coverage and nail topical depth.

## Google Search Console reports

**Anonymous queries**

This one’s big – and it solves a problem you might not even know you had.

Did you know Google hides a huge chunk of your keyword data? About 46% of all clicks in GSC come from queries marked as “anonymous.”

Now, you can uncover them. In the new Anonymous queries report, we match up GSC data with our Organic keywords report to surface those hidden terms – along with traffic, volume, and country stats. It’s the longtail visibility GSC doesn’t give you – but we do.

**Note**: GSC reports now have their own section in the top menu. You can go to All tools > star it for even quicker access.

## General

**Customizable Tool Access [Enterprise plans]**

A helpful update for Enterprise teams: tool access is now fully customizable. Admins and Members still get full access by default, but Guests will only see what you’ve granted permissions to.

Restricted tools will show up as greyed out in the menu, and anyone without access will see a clear “Access denied” message.
