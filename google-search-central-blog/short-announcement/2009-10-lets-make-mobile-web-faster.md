# Let's make the mobile web faster

*Cross-posted on the
[Google Code Blog](https://googlecode.blogspot.com/2009/10/lets-make-mobile-web-faster.html)*

This week, we've been
[celebrating all things mobile](https://googlemobile.blogspot.com/2009/10/captains-log.html)
across Google. Of course, this wouldn't be complete without a component for mobile web developers!
Two months ago we asked you to
[make the web faster](/search/blog/2009/06/lets-make-web-faster). Now, we've asked the
Google Mobile team for some best practices, tips, and resources for mobile web development, and
we've come up with a few things we wanted to share. "Go Mobile!" with our
[Make the mobile web faster article](https://code.google.com/speed/articles/mobile).
