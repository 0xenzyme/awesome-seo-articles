# Google Site Search: How to Do It Effectively [+ Examples]

## What Is a Site Search?

A Google site search involves using Google to search through one specific domain.

When you perform a site search, you’re telling Google to return results from only that specific site—not the entire internet.

To perform a site search, add “**site:**” in front of the domain URL you want to search:

![“site:www.domain.com” entered into Google search bar](https://static.semrush.com/blog/uploads/media/cb/be/cbbec0350e02524e24f199fb43e2d693/f7522ef209c2d21af8fc95a8b363bd8e/MlfK7_i0Kd5a8vdWUUD0oEvvq2VYtHAUyBr_GdQpY8Tg5D6IN_w7Ei47JRwVBOW4DVT4aEy9nOt8MzZwMqsDgl5930jNtoQA6HxDy0jPgVeasfe9Yg4SKa8Eeizu5lSdcEiyRlrGdxZZ.png)

### What Is Google's Site Search Operator?

Google's site search operator is the “**site:**” part of the Google site search:

!["site" highlighted in the “site:www.domain.com” site search](https://static.semrush.com/blog/uploads/media/ed/b9/edb93d8684e8df8a6dc2ea37e31397be/a9ee5ed9ce506c887316276f585c9eb1/S3pCXTDxaP7mlVXQ78B68blJvgBnGB2Ekpo3NIB8pz1_GNQFwm_09B-L8ei8GwaWnK1AvZwom-yyR4lUkMOtG0iCB7nqn9dIDOaGmFA_cj5Fmzp-7ZUV5bGf5aKxsrwrn6bUm7is6OY8.png)

The operator tells Google to restrict the search only to the website specified after it. Anything you type after “**site:www.domain.com**” will be searched for within Google’s records from that site.

## Reasons to Search a Site on Google

You can use search operators to:

- **Perform** [**competitor research**](https://www.semrush.com/blog/competitive-analysis/)**:** Use site searches to navigate your competitor’s URLs easily. Filter for specific keywords in the webpage content or title. Review your competitor’s blog for topics, new product releases, and other helpful information.
- **Find related content:** Site searches can identify existing content to reference in blog posts or web content. Combine site searches with query searches to find pages on an authoritative website referencing your blog topic.
- **Find content on your site:** You can run a site search on your domain to find older related content you can reference or refresh. If your website or blog is extensive, a Google site search is perfect for filtering through older content quickly. It can also help you find unsecure content on your site.

## How to Use Google to Search a Site

To search a site with Google, go to google.com and type “**site:**” followed by the URL you want to search.

For example, if we wanted to search within the Monday.com site, we would type "**site:monday.com**" into Google’s search bar and hit the search button.

This would show search results only from the Monday.com domain. Rather than the entire internet:

![Google's SERP for "site:monday.com" site search](https://static.semrush.com/blog/uploads/media/18/f7/18f75456a498b43db6019ac626c9f2d3/72d4f862b75823fdae5ed7d17c9a743d/_csHWcuBPFK36ZFCOvHhI4lyy6vuBIWpuu3j_KqDXigd2AmD8KE7UtDqzWZqkcqCurseOFa791I00gZRtJ47ndbq1_L5zNLzMXMdblGctVmH1cCzg_ptx4IpuaAEBY2lP2uSMVUHW1Um.jpeg)

However, it’s worth noting that there is a subtle difference between using "**site:domain.com**" vs. "**site:www.domain.com**" in Google site searches.

When doing a site search, check whether the site's homepage URL includes "**www**."

- If the URL contains www, use "**site:www.domain.com**" to exclude subdomains
- If “**www**” is **not** present, searching the root domain like "**site:domain.com**" will include subdomains

![A results from "https://canvas.moday.com" highlighted in Google's SERP for "site:monday.com" site search](https://static.semrush.com/blog/uploads/media/d7/3b/d73b694fb85a14d6a989228227bd5c3c/49b9283edb762f03678cc21489b06351/W_Gu34IsXRdwC_iipNel60Fu5LvUeDTht33v8suhNH_ojTCjY02uKQDHt8uVNElZWvI3rxLt6mbUlI1akLZjGc3NMyRgqvguNvAh38135AKHxhx7TJM2HWAHZF0dF3Mt9FYyJGfi8RId.jpeg)

## How to Refine Your Search Using Operators

The "**site:**" operator performs a basic site search. But you can refine your search using additional [Google search operators](https://www.semrush.com/blog/google-search-operators/).

Google search operators are special keywords you can add to the Google “**site:**” search to give you more control over what pages and content are shown in Google Search results.

Here are some helpful operators to use with site searching.

### Query Search

A query search lets you find pages on a specific website containing an exact search phrase or term.

To do this, enclose the phrase you want to search for in quotation marks:

`site:example.com "your query"`

For example, using "**site:semrush.com "SEO"**” would return results requiring the search query "SEO" to appear on the page.

![Google's SERP for "site:semrush.com "SEO"” site search](https://static.semrush.com/blog/uploads/media/56/6f/566fe763563700549c03e1f2725014a7/30c9bb72fca1a80d11fe6346d083cf9b/FqJJMDI_SFe8DkA3TrKL7FRwHtYz0G8wV7wprY5CmfyxXUS6nd7F9mr2_GYUNuKBRXTwEyGW6dXlBKbotds7bT7GL6okMr1u0igSv_qinArZ-D-qJkkm1SKRAzxSGhT4v1Qad_zHnorM.jpeg)

Using query searches with the "**site:**" operator can help find [internal link](https://www.semrush.com/blog/internal-links/) opportunities.

Internal links help search engines understand your site’s structure. Which can help improve your [SEO ranking](https://www.semrush.com/blog/seo-ranking/) on a particular page.

For example, the query search for **site:semrush.com "SEO"** finds pages that already mention SEO.

This would be perfect for adding an internal link point to the Semrush guide "[What Is SEO? Meaning, Examples & How to Optimize Your Site](https://www.semrush.com/blog/what-is-seo/)."

This relevant internal link is good for both users and search engines to help navigate the site and discover new pages.

### Negative Query Search

A negative query search excludes certain pages or terms from your site search.

To do this, you put a minus sign "**-**" before the word or phrase you want to leave out of the results.

`site:example.com -"your query"`

Google will filter out any search result that contains your negative query.

For example, you could use a negative query search (**site:semrush.com -“SEO"**):

![Google's SERP for "site:semrush.com -“SEO"” search query](https://static.semrush.com/blog/uploads/media/fb/94/fb94061868950a5e13a8f0398eeaa6ad/1b5f030214b833011d6004f11f711cd1/9Tcrfsw-IIh417rXXiJOio-H6uXpsfRwoGmZAsZPnFhB2CbES6mkcOyxMrPjCST6hXTteAAJdb7nj_PkB_uPwsxaflrXep1t5Lvn2jDrCHNa-1emj4g9tUxpz6n2xIbHGtskmGLb9xug.jpeg)

This search tells Google to return pages from the Semrush site that **do not** contain the exact phrase "SEO” on the page.

This could be useful for finding Semrush content around other topics like:

- Paid search
- Ecommerce
- Content creation
- Competitor research
- Social media marketing

So, this can help you filter out irrelevant content on broader sites.

### AND Search

Adding “**AND**” between two queries will narrow your search results to pages where **both** queries appear.

It looks like this:

`site:example.com "query" AND "query two"`

For example, you could use:

`site:www.semrush.com "keyword research" AND "competitor analysis"`

![Google's SERP for "site:www.semrush.com "keyword research" AND "competitor analysis"” site search](https://static.semrush.com/blog/uploads/media/8f/94/8f94a8a7a25a6dcf691e0e8b733ae810/25f2b47a86cb88592d847b619e12423e/0h74xhIzHDgnsziKcjjjTcS5yjM-4BaWpmZ3ZERci8LsbHHzeNUJd6_6nXd-m1Sy44Fe-PloKB42ZSuPuLv_R7oEHMsJ3G7Qi-WH-Q5uW34hHmeEaZ0mbkeRDojAVRZi_cWqBfLy8Mx0.jpeg)

So, result pages must contain **both** the terms "keyword research" and "competitor analysis" to surface.

Why is this useful?

Using AND searches would be very effective if you have a group of content that covers a broad topic but approaches it from different angles.

For example, digital marketing is a broad topic with subtopics like [SEO](https://www.semrush.com/blog/what-is-seo/), [pay-per-click (PPC)](https://www.semrush.com/blog/what-is-ppc/) advertising, [content strategy](https://www.semrush.com/blog/content-marketing-strategy-guide/), etc.

So, using the “**AND**” search operator on Semrush’s site, we can find pages that discuss:

- Keyword research AND PPC
- Competitor analysis AND content audits
- Rank tracking AND email marketing

This allows you to drill down to content covering multiple facets of digital marketing. We could then add internal links between those articles to connect them and help improve their SEO ranking.

### OR Search

Adding “**OR**” between two queries will expand your search results to include results where either of your queries appears.

It looks like this:

`site:example.com "query" OR "query two"`

For example: **site:semrush.com "search engine optimization" OR "SEO”** would return pages that mention either term.

![Google's SERP for "site:semrush.com "search engine optimization" OR "SEO”” site search](https://static.semrush.com/blog/uploads/media/0d/85/0d85790885a4a858da9398829abf4960/6911a3ae0f1a39913303b10f790d621a/mdiZIxlI7U9Rz85bqVMFqsB9ODR3RlTiSZwUx5VjA70RLZt_OFdeGeOspt3GQ8XFx7fKThhpwQ12kNy9ZiF5GnonFFSRUWcohnuI3Ab_jP87VseKQ4R55LDxeqnGjHkgg_G_VnUS7e5H.jpeg)

"Search engine optimization" and "SEO" mean the same thing in this case. So an “**OR**” search with those phrases would expand the results to pages containing either one.

An “**OR**” search allows you to include synonyms and alternate phrasing. Which is useful when a website may refer to the same thing differently.

For example:

`site:healthline.com "face mask" OR "facial covering"`

Or retrieving pages on variations or versions of something. Such as searching for multiple product iterations or versions:

`site:apple.com "iPhone 12" OR "iPhone 13"`

Or targeting multiple spellings or misspellings:

`site:example.com "yogurt" OR "yoghurt"`

### URL Search

You can also filter your site search results to only pages where your search term appears in the URL by using the “**inurl:**” operator.

It looks like this:

`site:example.com inurl:/blog/`

URL search is useful for finding:

- **Specific categories or subsections of a site**: Use topic words that commonly appear in those URLs
- **Particular file or page types**: Search extensions like .pdf, .html, .pnf, etc.
- **Primary home/landing pages on a topic**: Companies often use descriptive URLs to identify a subset of pages easily

You can also use the operator to size up your competition.

For example, the site search “**site:monday.com inurl:blog**” returns over 3,000 results:

![Google's SERP for “site:monday.com inurl:blog” search query](https://static.semrush.com/blog/uploads/media/72/e3/72e37aabb9213285a01fc11c8dda9540/cc2d9b6d8d2e02c9fdd821a0f94725c2/6q2oy1B1ISJrLfQlzwl31IDBO5zDc_banNmDNAAE8ew8e9BQ9CjNI1-cmsGcE54B7cT8gcNl6Msf8IeNXGw_3mx07nZtuU-rZTVXjlrDVt38GBH3ztbXswaY6zfgnyx8KB8tPD-xJRY8.jpeg)

Over 3,000 blog articles signal that Monday.com invests heavily in content marketing and owned media.

So, if you're a competitor to Monday, this provides a benchmark for comparing your company's blog content scope and volume. If you have 50 posts vs. their 3,000, it's clear a [content gap](https://www.semrush.com/blog/content-gap-analysis/) exists.

### Title Search

Another way to refine a site search is to use the “**intitle:**” operator. This returns only pages where your search terms appear in the title tag of the page.

It looks like this:

`site:example.com intitle: "query"`

Reasons to use “**intitle:**” search:

- Filter out unrelated peripheral content
- Focus on pages mainly about your query
- Find key overview pages on a certain topic

For example, “**site:monday.com intitle: ”project management”**” returns pages containing only “project management” in the [title tag](https://www.semrush.com/blog/title-tag/):

![Google's SERP for “site:monday.com intitle:”project management”” search query](https://static.semrush.com/blog/uploads/media/e6/f5/e6f5e9cff768e388d070a0447b89b28d/e6ae263c859e6457156eebd791d8d3c0/EoiQTIPAzxIQnSOyBRIg5LYijOA-AqltUhb0XdfGJArK-Xs2w8KqEUulgEY6MkwHFr1mmWbsOgv3v2NaiimfCNagEeIzTdiqs9tLFr6AicQgcGRUbjO2L4IsnTkQu8ONO_OYFRAQNEnb.jpeg)

You could use the title search operator to find outdated tags or content.

For example, “**site:monday.com intitle:2020**” returns the following pages:

![Google's SERP for “site:monday.com intitle:2020” search query](https://static.semrush.com/blog/uploads/media/8e/8a/8e8ae1d3b9a16c4b9865749c2f8841a9/26a76bf5e4794e4473d2b89b9cb48d11/D9IExeEakJugKzsZ9aDnV1PjVkZQr7cx1EyxIYdd4xTUnUkMKhl4Awj7uEwGDXo54A_-zqpyON98BLE1Vd5TSXymhYgax1qpjXd-KWSomqPqLtZEgg-VdEHm31-V7zG7lebjog3RcBik.jpeg)

You can also mix and match operators like “**inurl:**” and “**intitle:**” to target very narrow categories of pages:

What this does:

- “**inurl:blog**” returns only pages with "/blog/" in the URL so that it will be blog articles
- “**intitle:2020**” filters those blog pages further to those with "2020" in the title tag

For example, “**site:monday.com inurl:blog intitle:2020**” returns blog URLs that contain 2020 in the title tag:

![Google's SERP for "site:monday.com inurl:blog intitle:2020” search query](https://static.semrush.com/blog/uploads/media/28/28/2828d1415a0d7fb9473fe512563310e9/594c007d72e1a2c130214db88bfa75b6/sor3tWQfMkYsp717UGEsTsy6toiIdBSuR7uShR7EXSd_KFO3HqyCNPx9h0xxZRSCtPAcSZER2VTjGVNHWyDtLIhLVbWy50y4wEnKaeyGtUEECawRBVLoP-35XgxB-rJWr_oMrUGISzVF.jpeg)

Chaining together “**inurl:**” and “**intitle:**” builds customized site searches by combining criteria—in this case, isolating outdated blog content.

Another use case for the “**intitle:**” search operator is revealing how competitors write their title tags and opportunities to re-write yours for higher [click-through rates (CTRs)](https://www.semrush.com/blog/click-through-rate/).

For example, Monday.com may be curious to know how its competitor ClickUp writes its title tags for content focusing on project management.

The search operator would look like this:

`site:clickup.com intitle: "project management"`

Revealing the following search results:

![Google's SERP for "site:clickup.com intitle:"project management"" search query](https://static.semrush.com/blog/uploads/media/81/b6/81b69afb86dcf93b5594be08663328c3/750484d1d02dc9def5b2bcc0c8e5a818/WCx5a5WgI0raIccXnJgAq29TSi4wpS5wwLL3DJredk2iCqWMZDLWmLCKUtu4ZXVzWqjZhSZ8pNq_n_0r0sWM0-2NscjmQqVGOE7d0wVjuhjQkZasNU3Uqjr8TAlABjV4L-cWDJSDSYox.jpeg)

This searches for pages on ClickUp's site where "project management" appears in the title tag.

Monday.com could analyze these results to see what wording ClickUp uses around project management in titles. And assess differences that may present optimization opportunities in their title tags.

### File Type Search

Adding “**filetype:**” in front of your query will [search Google for a specific file type](https://www.semrush.com/blog/google-search-file-type/).

For instance, a Google site search for a PDF file would look like this:

`site:www.yourdomain.com filetype:PDF`

Common file types include:

- **PDF**: filetype:pdf
- **Word**: filetype:doc or filetype:docx
- **Excel**: filetype:xls or filetype:xlsx
- **PowerPoint**: filetype:ppt or filetype:pptx
- **JPG**: filetype:jpg
- **GIF**: filetype:gif
- **PNG**: filetype:png

This is useful for narrowing results to specific types of files.

For example, say you want to know if you have any outdated PDF files from your site that someone can find in search results.

This would retrieve all PDFs indexed from your domain. You could then scan through these results, checking for outdated PDFs that need to be refreshed or removed.

If we use this search operator on Monday’s domain, we can see they have a future of marketing style report in search results:

!["site:monday.com filetype:PDF" search query shows Monday's future of marketing PDF report](https://static.semrush.com/blog/uploads/media/64/9e/649ee42b8aef0ea70efa7fd8263c3e96/76bd91872a6781ebcc2b8163480988fa/QY6c2sQvp6QV9TUHKzCkx8cnqebIhXwCvvuvsZfHjvdMxUTN6VL0Or4envHLEc-vbWNGNNlL0yXSZxnOsJFFHEXCZ_NMkEP2kFnH94-LHu7i5j3tcn4pICDLqC11VZawRB7hQhn5J7d8.jpeg)

By running this file type search, you can audit outdated PDFs. This helps you focus on PDF content instead of manually combing through every page on your domain.

### Unsecure Content

You can use a search operator to identify unsecure, non-HTTPS pages on a website.

It looks like this:

`site:domain.com -inurl:https`

The "**-inurl:https**" filter will show pages on the domain that do not use "HTTPS" in the URL. This reveals any unsecure HTTP pages that could impact site security.

***Further reading**: [HTTP vs. HTTPS: Differences, Benefits, and Migration Tips](https://www.semrush.com/blog/http-vs-https/)*

For example, using this search operator on the Monday.com domain revealed the following results:

![Google's SERP for "site:monday.com -inurl:https" search query](https://static.semrush.com/blog/uploads/media/77/c5/77c5580d09f58f44f726bb060822f23f/e6b0125f370ec7b043872451f9d69287/0sUxX72Pw4jY7jYmlGVPuNq3P_oT0psQi8Jl2hasR778iQ7EiUCaUY3fIe7QKUjTI126pGvGxIXN0-I84UgtUs7w1WRtBa3RyDE43MtBFsx_mR5d0fJn_MvtvtaqLVU70997wfiwpb2G.jpeg)

The pages are showing as secure when you click through to them from the search results:

!["partners.monday.com" page shows the secure connection sign in browser](https://static.semrush.com/blog/uploads/media/15/7a/157a232702de14f26f3655117df830fa/f2e984bf167ce4be9aae763fec46853c/viS0YFojnX2R59psCaWV0GIyJ8fFJrP01QK546dUp4iSboZ6OUGpkEPfBKjnkxrfM90JzJPGFSlyM_kjowbE2CrpeyIph4H7w2PsRy9Zcpd-eFrGZTnujFkpuRs1BcRjxP5-P2ueUIzz.jpeg)

This is likely because the site has [301 redirects](https://www.semrush.com/blog/301-redirects/) from the old HTTP URLs to the secure HTTPS versions.

But it’s often best to use a tool like Semrush [Site Audit](https://www.semrush.com/siteaudit/) to confirm this. This tool will crawl the flagged pages to identify mixed content or unsecure internal linking.

## Find Content Issues on Autopilot

Manually using site search to check for content issues can be tedious. You can automate ongoing content checks using Semrush [Site Audit](https://www.semrush.com/siteaudit/) tool.

When starting a Site Audit scan, simply click “**Schedule**” in the settings.

!["Schedule" tab highlighted in the "Site Audit Settings" window](https://static.semrush.com/blog/uploads/media/6c/dd/6cdd523a147450e91915e71e8afc08af/a86393fe9db268c869a870b2b1a55159/2erZQ1fvV4quen7zonBpaDLUaYG9B9THJRxD3UhqLOT9eef9FoOATMlEQO8f7uFgkm2Ndb8e-d_RGEQz9m1-zBkd5UJr6UO0VPXvr9vJOxqpvSPfm5L32dCEIl7YEf_jjzh4V9ClnbRg.jpeg)

Then, select how often you want your site crawled to check for new content issues.

Automating this process saves time over manual checks and ensures a seamless experience for your visitors.
