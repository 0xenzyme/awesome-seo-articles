# Learn more about Googlebot's crawl of your site and more!

We've added a few new features to
[Webmaster Tools](https://search.google.com/search-console)
and invite you to check them out.

## Googlebot activity reports

Check out these cool charts! We show you the number of pages Googlebot's crawled from your site
per day, the number of kilobytes of data Googlebot's downloaded per day, and the average time
it took Googlebot to download pages. Webmaster tools show each of these for the last 90 days.
Stay tuned for more information about this data and how you can use it to pinpoint issues with
your site.

![googlebot activity report in webmaster tools](/static/search/blog/images/import/b0d1b9b3698dabb2d1e60a279c4d757b.png)

## Crawl rate control

Googlebot uses sophisticated algorithms that determine how much to crawl each site. Our goal is
to crawl as many pages from your site as we can on each visit without overwhelming your server's
bandwidth.

We've been conducting a limited test of a new feature that enables you to provide us information
about how we crawl your site. Today, we're making this tool available to everyone. You can
access this tool from the Diagnostic tab. If you'd like Googlebot to slow down the crawl of your
site, simply choose the **Slower** option.

If we feel your server could handle the additional bandwidth, and we can crawl your site more,
we'll let you know and offer the option for a faster crawl.

If you request a changed crawl rate, this change will last for 90 days. If you liked the changed
rate, you can simply return to Webmaster Tools and make the change again.

![crawl rate setting in webmaster tools](/static/search/blog/images/import/f1a705a791424e94cca0a99c8a6f5be5.png)

## Enhanced image search

You can now opt into enhanced image search for the images on your site, which enables our tools
such as
[Google Image Labeler](https://images.google.com/imagelabeler/)
to associate the images included in your site with labels that will improve indexing and search
quality of those images. After you've opted in, you can opt out at any time.

![enhanced image search setting in webmaster tools](/static/search/blog/images/import/55d999933e807e6620410f1f653eb232.png)

## Number of URLs submitted

Recently at [SES San Jose](/search/blog/2006/08/back-from-ses-san-jose), a webmaster
asked me if we could show the number of URLs we find in a Sitemap. They said that they generate
sitemaps automatically and they'd like confirmation that the number they think they generated is
the same number we received. We thought this was a great idea. Simply access the Sitemaps tab to
see the number of URLs we found in each sitemap you've submitted.

![number of urls found in a sitemap in the sitemaps feature in webmaster tools](/static/search/blog/images/import/81137c02b75d830fc8e10ff8d8f13078.png)
