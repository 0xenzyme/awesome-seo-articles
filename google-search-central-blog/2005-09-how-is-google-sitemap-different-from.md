# How is a Google Sitemap different from an HTML sitemap?

A Google Sitemap is an XML file that uses the
[Sitemap protocol](/search/docs/crawling-indexing/sitemaps/overview). This file lists
URLs in your site, along with optional descriptive information about those URLs (such as when they
were last updated and how often you modify them). You can create this XML file using our
[Sitemap Generator](/search/docs/crawling-indexing/sitemaps/overview)
or a
[third-party tool](https://code.google.com/sm_thirdparty.html).
Google Sitemaps are intended for processing by the Google Sitemaps program.

An HTML sitemap is intended for users of your site. Generally, this type of sitemap provides links
to the pages in your site, and may provide descriptions of those pages. We encourage the use of
HTML sitemaps. They make it easier for users to navigate your site. Also, as we talk about in our
[webmaster guidelines](/search/docs/essentials),
a clear hierarchy with text and links helps us index your site.

You can't submit an HTML sitemap to the Google Sitemaps program. However, if you are unable to
create or generate a Google Sitemap file in the Sitemap protocol format, you can
[submit a text file](/search/docs/crawling-indexing/sitemaps/build-sitemap#text)
that lists URLs in your site.
