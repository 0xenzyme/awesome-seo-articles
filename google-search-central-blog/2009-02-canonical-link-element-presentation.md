# Canonical Link Element: presentation from SMX West

A little while ago,
[Google](/search/blog/2009/02/specify-your-canonical)
and other
[search](https://ysearchblog.com/2009/02/12/fighting-duplication-adding-more-arrows-to-your-quiver/)
[engines](https://blogs.msdn.com/webmaster/archive/2009/02/12/partnering-to-help-solve-duplicate-content-issues.aspx)
announced support for a
[canonical link element that can help site owners with duplicate content issues](/search/docs/crawling-indexing/consolidate-duplicate-urls).

[SMX West](https://searchmarketingexpo.com/west)
