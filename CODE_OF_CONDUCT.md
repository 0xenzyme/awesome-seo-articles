# Code of Conduct

This project is a public article corpus and the scripts that maintain it. People interacting in issues, pull requests, and discussions are expected to:

- Stay on the corpus, the metadata, and the scripts.
- Critique the change, and leave personal attacks out of the thread.
- Quote only what is needed to point at a source URL or a file.
- Leave credentials, private documents, and unpublished material out of the repository and the issue tracker.

The maintainer may edit or close comments and pull requests that break these expectations, and may block repeat abuse.

Report a conduct problem to the maintainer at [@0xenzyme](https://github.com/0xenzyme).
