# Another update on the site: operator

We've fixed the
[issue with the trailing slash](/search/blog/2006/06/update-on-site-operator) in
`site:` operator queries. Queries for `site:www.example.com` and
`site:www.example.com/` should now return the same set of results.

Thanks for your feedback and patience.
