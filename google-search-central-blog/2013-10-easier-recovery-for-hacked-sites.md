# Easier recovery for hacked sites

We know that as a site owner, discovering your site is hacked with
[spam](https://support.google.com/websearch/answer/190597) or
[malware](https://support.google.com/websearch/answer/45449)
is stressful, and trying to clean it up under a time constraint can be very challenging. We've
been working to make recovery even easier and streamline the cleaning process–
[we notify webmasters](/search/blog/2009/11/new-software-version-notifications-for)
when the software they're running on their site is out of date, and we've set up a
[dedicated help portal for hacked sites](https://web.dev/articles/hacked)
with detailed articles explaining each step of the process to recovery, including videos.

Today, we're happy to introduce a new feature in Webmaster Tools called Security Issues.

As a
[verified site owner](https://support.google.com/webmasters/answer/35179),
you'll be able to:

- Find more information about the security issues on your site, in one place.
- Pinpoint the problem faster with detailed code snippets.
- Request review for all issues in one go through the new simpified process.

## Find more information about the security issues on your site, in one place

Now, when we've detected your site may have been hacked with spam or with malware, we'll show you
everything in the same place for easy reference. Information that was previously available in the
Malware section of Webmaster Tools, as well as new information about spam inserted by hackers, is
now available in Security Issues. On the Security Issues main page, you'll see the type of
hacking, sample URLs if available, and the date when we last detected the issue.

![The malware section of Webmaster Tools](/static/search/blog/images/import/59bd1db1a3a4be7b3eb114fc50dd7f34.png)

## Pinpoint the problem faster with detailed code snippets

Whenever possible, we'll try to show you HTML and JavaScript code snippets from the hacked URLs
and list recommended actions to help you clean up the specific type of hacking we've identified.

![A detailed view of a malware report, showing the compromising code snippet](/static/search/blog/images/import/8b8eaf417c619e0ac25115c97a90dd77.png)

## Request review for all issues in one go

We've also simplified requesting a review. Once you've cleaned your site and closed the security
holes, you can request a review for all issues with one click of a button straight from the
Security Issues page.

![How to request review for a website that's been cleaned of malware](/static/search/blog/images/import/35d2215d6e42c24d5a3831c7f966522a.png)

If you need more help, our updated and expanded
[help for hacked sites portal](https://web.dev/articles/hacked)
is now available in 22 languages. Let us know what you think in the comments here or at the
[Webmaster Help Forum](https://support.google.com/webmasters/community).
