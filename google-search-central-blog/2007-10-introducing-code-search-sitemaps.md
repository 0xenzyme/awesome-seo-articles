# Introducing Code Search Sitemaps

The Sitemaps team is
[continuing its trend](/search/blog/2006/11/introducing-sitemaps-for-google-news)
of extending the
[Sitemap Protocol](https://www.google.com/webmasters/tools/docs/en/protocol)
for specific products and content types. Our latest work with the
[Google Code Search](https://www.google.com/codesearch)
team now enables you to create Sitemaps that contain information about public source code you host
and would like to include in Code Search. There's more information about this
[new functionality on the Google Code blog](https://google-code-updates.blogspot.com/2007/10/tell-us-about-code-on-your-site-with.html).
If you're eager to get going, take a look at our Help Center
[documentation](https://www.google.com/support/webmasters/bin/answer.py?answer=75225),
create a Code Search Sitemap, sign into
[Google Webmaster Tools,](https://search.google.com/search-console)
and submit a Sitemap for Code Search!
