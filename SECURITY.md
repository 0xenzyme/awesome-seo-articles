# Security

This repository stores public blog articles and the scripts that fetch and index them. It is not an application with user accounts.

## Report a sensitive finding

Use [GitHub private vulnerability reporting](https://github.com/0xenzyme/awesome-seo-articles/security/advisories/new) for:

- a secret, token, or credential committed in the tree or history
- a script behavior that would leak local files or credentials during fetch

Do not open a public issue for those. Enable private vulnerability reporting in the repository settings if that link is unavailable.

## Everything else

Data bugs, missing frontmatter, duplicate URLs, and broken fetch lists belong in a public issue.
