# Introducing: Application Rich Snippets

Rich snippets help users determine more quickly if a particular web page has the information
they're interested in. We've previously introduced rich snippets for
[shopping](/search/docs/appearance/structured-data/product),
[recipes](/search/docs/appearance/structured-data/recipe),
[reviews](/search/docs/appearance/structured-data/review-snippet),
[video](/search/docs/appearance/structured-data/video), and
[events](/search/docs/appearance/structured-data/event), and most recently
[music](https://insidesearch.blogspot.com/2011/08/rich-snippets-help-you-find-music-more).

Before you install a software application, users might want to check out what others think about
it, and how much it costs. We are pleased to announce that starting today, you'll be able to get
this information right in search results.

Here's an example of what an application snippet looks like.

![Example search result for an application snippet](https://www.google.com/help/hc/images/webmasters/webmasters_1545432_rsmobileapps_en.png)

You can see application snippets from several marketplaces and review sites, including
[Android Market](https://market.android.com/),
[Apple iTunes](https://www.apple.com/itunes/), and
[CNET](https://www.cnet.com/). For information on how to add app markup
on your site, please refer to our
[Webmaster central article](/search/docs/appearance/structured-data/software-app)
and send any questions to our discussion
[help forum](https://support.google.com/webmasters/community/label?lid=41234c84d9491af8).
