# How to Search for File Types on Google

When you search for something on Google, the results are usually HTML pages—the normal webpages you see every day.

However, Google can also display non-HTML files, such as PDFs, spreadsheets, presentations, and Adobe files.

## How to Search Google by File Type

Use the “filetype:” search operator to narrow your search to a specific file type.

For example, a search for “filetype:pdf health” will show PDF files containing the word “health.”

![Google search results for “filetype:pdf health"](https://static.semrush.com/blog/uploads/media/5b/c0/5bc09c5fe7799dee4fc2003cf863fd2f/6GNQtj9wnGGiS4WRaw2n96RoGiEKZSVwYVWmGHjStBd9-oAEN0tAPzzvB8eg1WcbK8KKCAqDG3EAOE9WKe1-FmdDINvQUxD1CH6bxVe-gA8XZKpQM39hdMURfClRWaM_VSGhVORIXT_QqF3yY9ztPhk.png)

A search for “filetype:ppt travel” will show presentations related to travel.

![Google search results for “filetype:ppt travel”](https://static.semrush.com/blog/uploads/media/40/40/4040978cff00d447f8da930053a006f9/a0RFbfS4zx0-eNtU6eu7yraWXwBODtqeBRz_I-GdfFoWvQCPIlGgjpZIazAtlnO7J_q7fHXt32ojPHOrzscnJ6HODgPIepIwSIscuQUDoRsXUyUPJLgsQiyalTkSBpsXb6gBALAkftQu-x8X5_tMnAE.png)

Google can show these results because it can [crawl and index](https://www.semrush.com/blog/what-are-crawlability-and-indexability-of-a-website/) many types of files.

Google supports various search operators to locate these file types.

### What Are Search Operators?

[Search operators](https://www.semrush.com/blog/google-search-operators/) are special commands that help you refine Google searches.

For instance, “site:” limits results to a specific website. A query like “site:semrush.com SEO” shows only SEO-related pages from semrush.com.

![Google search results for “site:semrush.com SEO”](https://static.semrush.com/blog/uploads/media/01/fe/01fe8b1a79b1d6a5f6866b0407a81e96/CQGk8ehFXKOHEyii0e09Gl000NkAkl_T7strl-btwXLBMTEnQHoU26Rfghj0mVHuea2cRDy3ZWiRUyhx3hgc9f7kazQ8kHcztjPWclK8suBFyIK35VKx5ygFOdEwd6tmCz6fR9e-t7sCd0AwZxAckD0.png)

## Ensure Your Files Get Indexed in Google

If you have content in different file types (e.g., xls, pdf, ppt, etc.) that you want to appear in Google search results, you need to ensure Google can crawl and index them.

Google cannot index files blocked by the [X-robots-tag noindex directive](https://www.semrush.com/blog/robots-meta/). If you publish PDF, XLS, PPT, or other file types, check that Google can crawl and index them.

## Key Takeaways

- Google can find more than just HTML pages. Use the “filetype:” operator to locate PDFs, spreadsheets, presentations, and more.
- Google can crawl and index file types such as XLS, PPT, PDF, and TXT.
- Confirm that Google can index your non-HTML files by removing unnecessary noindex directives. The [Site Audit](https://www.semrush.com/siteaudit/) tool can help you detect these issues.
